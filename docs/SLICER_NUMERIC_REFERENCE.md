# Slicer Numeric Constants and Defaults

Source snapshot: 21 October 2026. Toolset C++ only; application presets and third-party internals are excluded. No compilation was performed.

Entries list direct numeric assignments and meaningful numeric literals used in calculations. Calculated variables are not listed as constants: their literal coefficients or thresholds are identified by purpose instead. Loop counters, indices, connectivity dimensions, status codes and routine zero initialization are omitted.

Public declarations appear first. The second section covers implementation-local values, including locals inside public methods; `internal` does not imply that every containing function has the C++ `private` access specifier. Namespace utility declarations have no C++ public/private qualifier and are grouped with the public API.

Lengths use internal mm unless noted otherwise. Relative and barycentric thresholds are dimensionless; squared lengths, areas and volumes must not be treated as length tolerances. Links identify snapshot source lines.

## Classification

- **Value**: dimensional thresholds/defaults, unit-conversion constants, counts, angles, identifiers or switches. Dimensional values depend on the coordinate unit; counts and switches do not. See the unit column rather than assuming every value must be scaled.
- **Ratio**: dimensionless multipliers, normalized weights and relative tolerances. Uniform m/mm conversion does not require scaling these constants. This does not guarantee the whole algorithm is scale-invariant when other absolute tolerances remain.
- Under coordinate scaling by `s`, length thresholds scale by `s`, area/squared-distance thresholds by `s^2`, and volume thresholds by `s^3`. Gradient thresholds require the field's own scaling law; a dimensionless field has a gradient with inverse-length units.
- A threshold applied to an unnormalized vector is not classified as a ratio merely because it is small. Multiple literals on one row can have different dimensions, specified separately below.
